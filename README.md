## 🔄 User Journey

The designed experience follows a simple shopping flow:

**Home → Browse Products → Select Product → Add to Cart → Checkout**

The goal was to keep each step clear and reduce unnecessary complexity in the shopping journey.

## 📚 What I Learned

This project helped me understand how **UI design and user experience work together** to create interfaces that are not only visually appealing but also easy to use.
